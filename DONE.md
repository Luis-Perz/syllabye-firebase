A story is considered Done when all of the following criteria are met:    
Requirements met: The story's acceptance criteria have been satisfied.  
Tested: The changes have been tested, and no known critical bugs remain.  
Code committed: The code has been committed and pushed to the team's repository.  
Pull request created: A pull request has been opened with a clear description of the changes and a reference to the corresponding story.  
Reviewed and approved: The team has reviewed and approved the pull request.  
Merged: The pull request has been merged into the designated target branch.
