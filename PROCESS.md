This document describes how we implement scrum in our team.

# SCRUM SCHEDULE
- each lasts approximately 2 weeks
- Sprint will start Monday but Stand-ups will be held on Tuesday's in-class.
- Any questions will be sent through Discord by Sunday before the sprint ends
- All Backlogs will be stored and updated through Github.

# WEEKLY STANDUP
- Review what was completed during the week
- Assign tasks
- Identify any issues

# BACKLOG
- prioritized from top to bottom (High to Low priority)
- Definition of Ready: a backlog item is pulled from product backlog to sprint backlog
- Definition of Done: code is merged to the Main branch in the GitHub repo.
